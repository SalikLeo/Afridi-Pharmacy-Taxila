# Afridi Diagnostic Centre - Management System & POS

Desktop Point of Sale (POS) & Pharmacy Inventory Management System built with Electron and SQLite.

## Features
- **Point of Sale (POS):** Fast barcode & formula-based search, multi-item invoicing, discount calculation, thermal 80mm receipt generation.
- **Medicine Stock Management:** Categorized inventory by dosage form, batch tracking, expiry date monitoring, low stock alerts, and real-time inventory valuations (Cost, Retail, Margin).
- **Distributor & Company Ledgers:** Purchase logging, supplier ledger statements, balance tracking, and returns management.
- **Patient & Customer Accounts:** Client ledger history, receivables tracking, and prescription management.
- **Expense Tracking:** Expense categories, monthly statements, and profit/loss reporting.
- **Thermal Printing:** 80mm receipt and stock audit report printing.
- **Local & Offline:** Standalone offline SQLite database with automatic backups and data integrity controls.

## Tech Stack
- Electron.js
- Better-SQLite3
- Tailwind CSS / Vanilla JS & Lucide Icons

## Setup & Development
```bash
# Install dependencies
npm install

# Run application
npm start

# Build Windows Installer
npm run dist
```
